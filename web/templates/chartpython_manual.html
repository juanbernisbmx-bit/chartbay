Parte 1

Usar ChartPython

ChartPython es un notebook parecido a Jupyter que corre entero en tu navegador. Escribís código en celdas, lo ejecutás y el resultado aparece debajo. Python y sus paquetes viven en la página: no hay que instalar nada y los archivos que subís no llegan a ningún servidor.

Primeros pasos{{ ancla('primeros-pasos') }}

  1. Entrá a ChartPython. Arranca con un notebook que tiene una celda vacía.
  2. Hacé clic en la celda, escribí 2 + 2 y apretá Shift+Enter.
  3. La primera vez tarda: el navegador descarga Python y sus paquetes, unos 115 MB. Quedan en la caché, así que las próximas veces arranca en pocos segundos.
  4. El resultado aparece debajo de la celda, marcado con Out[1]:.
{% call py() %} 2 + 2 {% endcall %} {% call salida() %} 4 {% endcall %}

Debajo del notebook, la barra de estado cuenta qué está haciendo Python: Python apagado (todavía no arrancó), Preparando Python…, Python listo, Ejecutando… con los segundos que lleva, y Python se detuvo si algo lo cortó. También muestra la memoria que usa y la hora del último guardado.

Todo queda en esta computadora. Python, los notebooks y los archivos que subís se guardan en este navegador. Si borrás los datos del sitio o abrís ChartPython en otro navegador, no van a estar: descargá el .ipynb de lo que quieras conservar.

Celdas y atajos de teclado{{ ancla('celdas') }}

Hay dos tipos de celda: de código, que ejecuta Python, y de texto, para escribir notas con formato. Se agregan con los botones + Código y + Texto.

Las celdas comparten las variables: lo que definís en una se puede usar en las demás. Lo que importa es el orden en que las ejecutaste, no dónde están en la página. El número de In [3]: dice cuándo corrió cada una, y In [*]: que está esperando o corriendo.

{% call py() %} precio = 3450 cantidad = 2 {% endcall %} {% call py() %} precio * cantidad {% endcall %} {% call salida() %} 6900 {% endcall %}

Debajo de la celda se ve el valor de la última línea. Para ver algo del medio usá print(), y para mostrar varias tablas en una misma celda, display(), que ya está disponible sin importar nada. Un punto y coma al final de la última línea oculta su valor.

{% call py() %} subtotal = precio * cantidad print("Subtotal:", subtotal) print("Con IVA:", subtotal * 1.21) subtotal > 5000 {% endcall %} {% call salida() %} Subtotal: 6900 Con IVA: 8349.0 True {% endcall %} {% call py() %} display(precio, cantidad) precio * cantidad; {% endcall %} {% call salida() %} 3450 2 {% endcall %}

Guardar, abrir y exportar notebooks{{ ancla('notebooks') }}

  • Se guarda solo mientras escribís; la barra de estado muestra la hora del último guardado. Ctrl+S lo guarda en el momento.
  • El selector de arriba lista los notebooks de este navegador. Nuevo, Renombrar y Borrar hacen lo que dicen; borrar pide confirmación.

  • Descargar .ipynb baja el notebook en el formato de Jupyter, que también abren VS Code y Google Colab.
  • Abrir .ipynb importa un notebook. Muestra las salidas que traía sin ejecutar nada; para regenerarlas, ejecutá las celdas.

Interrumpir y reiniciar Python{{ ancla('reiniciar') }}

En un navegador la única forma de frenar un código que no termina es apagar Python y volver a prenderlo. Por eso ■ Interrumpir (I I) y ↻ Reiniciar (0 0) tienen el mismo efecto:

  • Se pierden las variables, los import y los archivos creados por Python.
  • Se conservan las celdas, sus salidas y los archivos que subiste, que vuelven a /mnt/data antes de la próxima ejecución.

Después de reiniciar, ⏭ Ejecutar todo corre las celdas de código en orden y recupera todo. Si la barra dice Python se detuvo (por ejemplo, porque se quedó sin memoria), es lo mismo: volvé a ejecutar.

{% call py(ejecutar=false) %} # No lo ejecutes: este bucle no termina nunca y hay que interrumpirlo while True: pass {% endcall %}

Antes de compartir un notebook, reinicialo y usá Ejecutar todo. Si corre de arriba a abajo sin errores, cualquiera que lo abra va a llegar al mismo resultado.

Diferencias con Jupyter{{ ancla('diferencias') }}

Si venís de Jupyter o de Colab casi todo funciona igual. Estas son las diferencias que se notan:

No hay comandos mágicos

%timeit, %matplotlib inline, !pip install y pd.read_csv? dan SyntaxError: no son Python, son de IPython. Para la ayuda de una función usá help(), y para medir cuánto tarda algo, time:

{% call py() %} import time inicio = time.perf_counter() suma = sum(range(1_000_000)) print(f"Tardó {time.perf_counter() - inicio:.3f} segundos") {% endcall %}

display() ya viene incluido. Si copiás código que hace from IPython.display import display, borrá esa línea:

{% call py(error="ModuleNotFoundError") %} from IPython.display import display {% endcall %} {% call salida_error() %} ModuleNotFoundError: No module named 'IPython' {% endcall %}

No se pueden pedir datos con input()

{% call py(error="RuntimeError") %} nombre = input("¿Cómo te llamás? ") {% endcall %} {% call salida_error() %} RuntimeError: input() no está disponible en ChartPython. Asigná el valor en una celda o cargá un archivo. {% endcall %}

Los enteros de NumPy son de 32 bits

Python corre en WebAssembly de 32 bits, y ahí el entero por defecto de NumPy es int32: llega hasta 2.147.483.647. Pasado ese número la cuenta da mal sin avisar, algo fácil de cruzar con montos en pesos.

{% call py() %} import numpy as np np.array([2_000_000_000, 2_000_000_000]).sum() {% endcall %} {% call salida() %} -294967296 {% endcall %} {% call py() %} np.array([2_000_000_000, 2_000_000_000], dtype="int64").sum() {% endcall %} {% call salida() %} 4000000000 {% endcall %}

Regla práctica: escribí "int64" en lugar de int. pd.read_csv() y pd.to_numeric() ya usan 64 bits, pero astype(int), np.array([...]) y np.arange() usan 32. Más detalles en Tipos de datos.

Límites de una celda

  • Una celda muestra hasta 1 MiB de salida o unos 1000 print. Lo que pase de ahí se corta con un aviso, pero el código sigue corriendo hasta el final.
  • El código de una celda puede ocupar hasta 100 KiB.
  • Para mirar datos grandes, preferí head(), sample() o un resumen antes que imprimir fila por fila.

Variables, números y texto{{ ancla('variables') }}

Una variable es un nombre para un valor. Se crea con = y no hace falta declarar el tipo. Lo que va después de # es un comentario: Python lo ignora.

Texto

Listas y diccionarios{{ ancla('colecciones') }}

Una lista guarda valores en orden. Las posiciones se cuentan desde 0 y los números negativos cuentan desde el final.

{% call py() %} precios = [3450, 5200.5, 1100, 2890] print(precios[0]) # el primero print(precios[-1]) # el último print(precios[1:3]) # posiciones 1 y 2: el 3 no entra precios.append(990) # agregar al final print(len(precios), sum(precios), max(precios)) print(sorted(precios)) {% endcall %} {% call salida() %} 3450 2890 [5200.5, 1100] 5 13630.5 5200.5 [990, 1100, 2890, 3450, 5200.5] {% endcall %}

Un diccionario guarda pares clave → valor. Sirve, por ejemplo, para tablas de equivalencias.

{% call py() %} producto = {"nombre": "Yerba 1kg", "precio": 3450, "stock": 12} print(producto["precio"]) print(producto.get("marca", "sin marca")) # valor por defecto si la clave no está producto["stock"] = 10 # cambiar o agregar un valor for clave, valor in producto.items(): print(clave, "→", valor) {% endcall %} {% call salida() %} 3450 sin marca nombre → Yerba 1kg precio → 3450 stock → 10 {% endcall %}

Condiciones y bucles{{ ancla('control') }}

Python usa la sangría para saber qué líneas van dentro de un if o de un for: cuatro espacios después de la línea que termina en :.

{% call py() %} stock = 3 if stock == 0: print("Sin stock") elif stock < 5: print("Quedan pocas unidades") else: print("Hay stock") {% endcall %} {% call salida() %} Quedan pocas unidades {% endcall %}

Para comparar: == (igual), != (distinto), <, <=, >, >=. Para combinar condiciones: and, or y not; in pregunta si un valor está en una lista o en un texto.

{% call py() %} for provincia in ["CABA", "Córdoba", "Mendoza"]: print(provincia.upper()) for numero, precio in enumerate([3450, 1100], start=1): print(numero, precio) for producto, precio in zip(["Yerba", "Azúcar"], [3450, 1100]): print(f"{producto}: $ {precio}") for mes in range(1, 4): # 1, 2 y 3: el 4 no entra print("Mes", mes) {% endcall %} {% call salida() %} CABA CÓRDOBA MENDOZA 1 3450 2 1100 Yerba: $ 3450 Azúcar: $ 1100 Mes 1 Mes 2 Mes 3 {% endcall %}

Leer y explorar un CSV

pandas guarda una tabla en un DataFrame: filas, columnas con nombre y un índice que identifica cada fila (al leer un CSV son los números 0, 1, 2…). Cada columna, por separado, es una Series.

El CSV de práctica{{ ancla('csv-practica') }}
